# 实验一对上下文取值口径的敏感性

两组使用同一批 2,047 条首次请求、同一组九种芯片、五场景等权以及相同的硬件预算。Observed 对每个实际长度计算 FLOPs。Upper edge 将请求映射到所在区间的上界，11 个上界覆盖 1K–1M。重复实验的命令见上一级 README。

[sweep_comparison.pdf](sweep_comparison.pdf) 为两种扫参结果。左图 (a) 采用实际长度，中图 (b) 采用区间上界，黑框标出区间赢家改变的格子。右图 (c) 在相同参考面积 α=0.327 处比较各档赢家相对基线的加速比，纵坐标取功耗档中点。

| 指标 | 实际长度 | 区间上界 |
|---|---:|---:|
| 每请求平均建模长度（tokens） | 91,339 | 131,989 |
| 最紧预算点（α=0.327，β=1）的最佳固定配比 | 1:4:8 | 1:4:8 |
| 该点全场景综合加速比 | 1.137242× | 1.145448× |
| 该点基线 / 最优的模型平均时间（秒） | 2.2550 / 1.9828 | 3.3476 / 2.9225 |
| 250 个预算格的赢家数（1:4:8 / 1:6:12 / 1:8:16） | 40 / 86 / 124 | 37 / 86 / 127 |
| 全预算矩形均匀加权时的最佳固定设计及其加速比 | 1:8:16，1.358272× | 1:8:16，1.371040× |

240/250 个格子选择一致，另外 10 个格子也只在这三种设计间切换。[逐格赢家及其区间得分](grid_comparison.csv)。每档选覆盖参数区间最大的方案。所有格子的赢家得分按上界计算时平均提高 0.01193×，范围 +0.00296× 至 +0.02494×。这个比较允许赢家随长度口径变化。

α=0.327 切片的 10/10 个显示档选择一致：[1.0,1.2) 为 1:4:8、[1.2,1.4) 为 1:6:12、[1.4,2.0] 为 1:8:16。两个口径的区间加速差在 +0.00757× 到 +0.01553× 左右，精确数值见 [十档得分](slice_comparison.csv)。整核开启事件会造成档内切换。在精确的 β 切片上，仅 [1.20155168,1.21840935) 的赢家不同，实际长度选 1:4:8，上界选 1:8:16。从 β≈1.38105 起两种口径持续选 1:8:16。[精确切换区间](slice_intervals.csv)。

“按上界”适合比较配比选型，但会提高建模的绝对时间。上述结果只度量三类精度的理想 GEMM 计算时间。
