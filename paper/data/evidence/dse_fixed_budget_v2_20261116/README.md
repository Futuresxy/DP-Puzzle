## 口径与复现

- 固定数据：`data/evidence/v41_core_20261116/`；DP 成本：`data/DP_area_power/dp11_area_power_fixed_20261116.csv`。

- α=0.3、β=1；D=256、N0=36、1 GHz。每核外围面积近似固定，本地供数充分。以三精度测量功耗的最大值决定一个固定物理部署数。

- 实框表示双预算平均时间最优，虚框表示仅面积最优；所有格内数字仍是双预算结果。虚框所圈数值不表示仅面积时的加速比。
- `hardware.csv` 为九配比成本/部署，`workload_gains.csv` 为双预算 63 项比较，`area_only_gains.csv` 为同面积去功耗限制的 63 项比较；`portfolio_context.csv` 保留 β=1/1.5、A–E/A–F 的既有跨场景评价，便于核对用户所指的历史图。

## 三个发现及整体选择

1. 功耗约束改变选型。仅面积下 A/C 最优为 1:8:16 / 1:2:16；β=1 后转为 1:2:4 / 1:2:8。九候选下 A 并非 1:4:4 最优，因此不采用这一原先推测，也不宣称所有迁移路径严格单调。
2. 适度非对称增配保留部署密度。1:2:8 / 1:4:8 单 DP 的 E 峰值相同，但双预算下为 32/20 SM，前者芯片 E 峰值高 60%。
3. 以固定芯片评价整体表现：β=1 时 1:2:8 是 B–E 各列及 A–F 汇总平均时间最优；A–F 加速 1.147318 倍，排除激进 F 后 A–E 仍以 1.103447 倍最优。β=1.5 时均衡平均时间最优才是 1:4:8（A–F 为 1.361649 倍、A–E 为 1.333989 倍），两种预算不能混为同一张图的结论。

平均时间最优不等于最坏相对损失最小：例如 β=1、A–E 的 minimax 为 1:2:6。All 使用预设均衡请求分布；不是对所有未来分布的普遍最优声明。F 的单独最优 1:2:12 作为格内数据保留，不再作为第三条主发现。
