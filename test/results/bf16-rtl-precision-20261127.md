## ID 113 的误差从哪里进入

E96 顶层将 BF16 交给四个共用基本组，每组做四个 BF16 乘积。S2 生成精确的 BF16 尾数积，并按组求乘积指数最大值。S3 把各乘积的幅值右移到共同坐标，幅值向零截断后转补码。设组内去偏乘积指数的最大值为 `M`，S3 的最小步长为 `2^(M - (LOCAL_W - 2))`。默认保留 26 个小数位，BF16 乘积占 14 个原始小数位，因此最多有 12 个指数差能保证原始乘积低位全部保留。指数差更大时，具体是否丢位由乘积低位决定。[基础组实例](../../src/verilog/top/common/dp_top_mixed.v) · [局部对齐](../../src/verilog/lane/dp_lane_align.v) · [向零移位](../../src/verilog/arithmetic/dp_rtz_shift.v)

| 乘积位置，从 0 起 | 组内最大指数 `M` | 本项指数差 | 精确乘积 | S3 对齐后 | S3 带符号偏差 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 4 | 12 | 13 | −31229 / 32768 | −15614 × 2⁻¹⁴ | +4 / 131072 |
| 8 | 13 | 15 | −33495 / 65536 | −4186 × 2⁻¹³ | +14 / 131072 |
| 10 | 13 | 16 | 59989 / 131072 | 3749 × 2⁻¹³ | −5 / 131072 |

三项误差合计为 `13 × 2^-17`，另有一项量级约 `1.28×10^-38` 的正乘积在 S3 清零。两个大组和约为 −12200.98 与 +11880.34，全部项加 C 后只剩约 −304.94。最终 FP32 的步长是 `2^-15`，所以 S3 的净偏差折合约 3.25 个输出 ULP。该笔 S6 的公共指数是 13，窗口步长是 `2^-25`，四个组和及 C 均可精确落位，两个扩展组的叶子为零。S7 观测和为 `-10232032276 × 2^-25`，约 −304.9383245707，S8 对这个值正常做最近偶数舍入，产生 `c398781b`。精确点积加 C 约 −304.9384237528，舍入为 `c398781e`。[S6 全局对齐](../../src/verilog/top/common/dp_mixed_global_align.v) · [S8 舍入](../../src/verilog/arithmetic/dp_fp32_round.v) · [E96 断点](../runs/verilog/20261127T024306883361Z/verilator-verilog/bf16/cutpoints.txt)

ID 116 同样受抵消影响，S3 将第 12 项的幅值截短了 `2^-25`，约为该输出的半个 FP32 ULP，足以改变最后的舍入。ID 122 的和约为 8013.57，抵消较少，但 S3 仍把结果从 FP32 舍入中点的一侧移到另一侧。三笔在默认窗口下都没有 S6 新增损失。

`29/40` 让原先的 ID 113、116、122 都逐位匹配数学参考。基础顶层和八个混合顶层均为 959/961 数学逐位相同，剩余偏差统一出现在 ID 185、190，两笔各 1 ULP。有符号的截断误差会互相抵消，也会同向叠加，因此增加一位可以缩小截断上界，单笔 ULP 仍可能回升，例如 ID 113 在 `31/40` 的结果。对这套语料，`29/40` 是扫过的最小 1 ULP 配置。

新测试用可精确编码的 BF16 数构造 `+1 − 1 + 残差`。三笔 C 均为零，扩展端口填有 NaN 编码，用于同时检查 BF16 的扩展屏蔽。

| 定向 ID | 乘积布局 | 精确结果 | 默认 28/40 | 首个恢复所测配置 |
| ---: | --- | ---: | ---: | --- |
| 0 | 三项同组 | 2⁻²⁸ | 0 | 30/40，S3 保留残差 |
| 1 | 三项分属三个组 | 2⁻²⁸ | 2⁻²⁸ | 默认保留残差 |
| 2 | 三项分属三个组 | 2⁻⁴⁰ | 0 | 28/64，S6 保留残差 |

ID 0 和 1 计算相同的数学表达式。改变乘积所在组即可改变 28/40 的数值结果，说明支配精度的是**抵消前两次有限窗口对齐**。特别是 ID 0 和 2，输出为零时的绝对偏差分别只有 `2^-28` 和 `2^-40`，但相对误差是 100%。这里的 ULP 用有序 FP32 编码步数统计，零和非零正规数之间跨越多个 binade，步数很大。语料最大 3 ULP 因此只描述这 961 笔。

## 架构取舍

- **当前语料优先评估 S3 增一位。** `29/40` 将组内量化步长减半，保留最直接影响 ID 113 的低位。现有 `LOCAL_W` 同时决定 T/H/Q 共享移位器、补码叶、组内加法器以及部分 S5 token 的宽度。默认参数变更前，需要以同工况检查面积、时序、功耗，并重跑跨精度回归。
- **更严格的抵消场景需要保留有符号残差。** 若目标是减少混合指数、强抵消下的丢位，可以评估只给 H 路保留额外低位，或将部分丢位延后到更宽的规约。单个 sticky 只能表示某处有非零低位，无法表达多个正负残差相消后的数值。S6 也需要纳入强抵消精度要求。

## 重放

源码基准 `14e938b4918d8e41622b8eca0cc3ea5e89d185ad`，混合顶层使用 Verilator 5.034，基础顶层使用 Icarus Verilog 12.0，均为冻结的手写 Verilog。E96 默认全回归也通过 11 种格式的 10747 笔原生数据及三组参数断点和协议检查。详情及输入、结果指纹见 [JSON](bf16-rtl-precision-20261127.json)。

```sh
cmake -S src/cmodel -B src/cmodel/build -DCMAKE_BUILD_TYPE=Release
cmake --build src/cmodel/build -j 4
python3 test/run_mixed_verilog.py --frontend t8h16q32e96 --bf16-only
python3 test/run_mixed_verilog.py --frontend t8h16q32e96 --bf16-only --local-w 29
python3 test/run_mixed_verilog.py --frontend t8h16q32e96 --bf16-only --global-w 64
python3 test/run_verilog.py --phase existing --simulator iverilog
```

可用 `--verilator` 指定安装路径。若 Verilator 使用的 ccache 目录不可写，设置 `CCACHE_DISABLE=1` 可直接编译。
